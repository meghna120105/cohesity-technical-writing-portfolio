## Projects and Documents

### 1. Markdown Documentation Checker (`scripts/markdown_checker.py`)

A command-line Python script that reads Markdown files and reports basic quality issues.

**Planned checks:**

- Whether the file is empty
- Whether a title or heading exists
- Whether any lines have trailing whitespace
- Whether relative links point to files that exist (where reasonably possible)

**Known scope:** This is a simple learning tool, not a full Markdown linter. Its limitations will be documented in this repository.
